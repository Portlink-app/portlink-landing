# Vendored design system: lint waivers

The CSS in this folder is generated by `portlink-design-system` (`npm run ds:sync`) at the pinned
version in `VERSION`. This repo never edits it (`AGENTS.md`), and changing it means a design-system
release plus a vendored version bump, which David approves (`CLAUDE.md`, irreversible steps). The
sync writes only its five mapped files, so this note survives a re-sync.

The waivers below apply to this folder only (the lint reads the nearest `DIRECTION.md` upward
from each file); the site's own authored code stays fully linted.

signature-ok: glass https://portlink-design-system.netlify.app vendored DS bundle; the backdrop blur belongs to the design-system release, not this repo
signature-ok: pill-cta https://portlink-design-system.netlify.app vendored DS bundle; the full-radius badge belongs to the design-system release, not this repo

Chose: a folder-scoped waiver. Over: editing generated CSS (overwritten on the next sync) or a
repo-wide waiver (would hide authored glass or pill controls). Because: the root fix lives in the
design-system source. Revisit if: the next DS release removes the blur and full-radius rules; then
delete this file.
